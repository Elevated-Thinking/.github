# .github

Public organization profile, community configuration, and external security-reporting entry point for Elevated Thinking.

[CONTRIBUTING.md](CONTRIBUTING.md) contains organization contribution guidance; [SECURITY.md](SECURITY.md) remains the public security policy. Version-dependent contribution and build instructions belong to each product repository. Organization members use the private `.github-private` handbook for internal procedures and repository-specific review/check summaries.

Designer has Write on this repository; Developer has Triage through the organization-wide role; other non-owner members have Read; organization owners retain Admin. Existing default-branch PR protections remain in effect. This repository is public and can be read without organization membership.
